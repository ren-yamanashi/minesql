# MineSQL 仕様

## メイン機能

- コネクションハンドラー
- クエリキャッシュ
- SQL パーサー
- オプティマイザ
- エグゼキュータ
- ストレージエンジン

### コネクションハンドラー

- ネットワーク接続
- ユーザー認証
- 権限管理
- 参考: https://dev.mysql.com/blog-archive/mysql-connection-handling-and-scaling/

### SQL パーサー

- SQL 文の構文解析

### オプティマイザ

- 実行計画の作成

### エグゼキュータ

- 実行計画に従って (ストレージエンジンにアクセスし) 処理を実行

### ストレージエンジン

- ディスク
- バッファプール
- ログ
  - Redo ログ
  - Undo ログ
- トランザクション
- ロック
