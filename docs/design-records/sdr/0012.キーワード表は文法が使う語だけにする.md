# キーワード表は文法が使う語だけにする

## Motivation

字句解析器は、切り出した語がキーワードか識別子かをキーワード表で判定する。MySQL のキーワード表には約 800 語があり、そのうち約 300 語は予約語 (引用しないと識別子に使えない語) である。MineSQL のキーワード表にどこまでの語を含めるかを決める必要があった

## Decisions

- キーワード表には、MineSQL の文法に現れる語だけを含める
- 予約語と非予約語の区分は MySQL に従う
  - MySQL で識別子としても使える語 (`ident_keyword` に現れる語) は、MineSQL でも識別子として受理する
- MySQL の予約語であっても MineSQL の文法に現れない語 (`WINDOW`、`CUBE` など) は、MineSQL では識別子として扱う

## Context

キーワード表の範囲は、互換の向きを決める

- MineSQL が予約する語が MySQL の予約語の部分集合なら、「MySQL で通る SQL は MineSQL でも通る」という向きの互換が保たれる
- 逆向き (MineSQL で通る SQL が MySQL でも通る) は、学習用の実装では重要ではない

MySQL の予約語をすべて持つ案は、逆向きの互換を得る代わりに、文法で使わない語を字句解析器が大量に持つ。文法に語を足すたびに表にも足せばよいので、必要な語だけを持つ方を選んだ
